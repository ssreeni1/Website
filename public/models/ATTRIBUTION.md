Original: https://sketchfab.com/3d-models/mercedes-f1-w14-free-26fda66f3e8a48d5a636056f8a64e299
License: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/

Asset: https://s3-eu-west-1.amazonaws.com/fetchcfd/original/file-1683823947211.glb

This is the artist's W14 interpretation, not manufacturer CAD. Adaptations:
schematic materials, sponsor decal removal, scale normalization, baked source
transforms, and custom hub-centered steering/rolling rigs. No endorsement implied.

### Fast runtime derivative

`formula-runtime-v1.bin.gz` and its uncompressed compatibility fallback are
generated by `scripts/prepare-formula.mjs` from the original above.
The derivative retains every rendered mesh, vertex, triangle, hub transform,
and wireframe contour. Positions are rounded to a 0.00002 m grid (maximum
0.01 mm per-axis error); wheel normals use 16-bit octahedral encoding. Tests
compare all positions, triangle winding, outlines, bounds, and rig metadata.
Unused original textures, decals, UVs, and unlit-body normals are not shipped.
Source transforms, wheel rigging, and wireframe extraction run offline, not
on each visitor's main thread. Meshoptimizer compression and gzip package the
result; no mesh simplification is used. The original CC BY 4.0 attribution applies.

## Retained earlier model

`formula1.glb` is an optimized and visually restyled derivative of
“McLaren MP4/5 — Formula 1” by dark_igorek, downloaded from
https://www.get3dmodels.com/vehicles/formula-1-car/

The source model is licensed under Creative Commons Attribution 4.0:
https://creativecommons.org/licenses/by/4.0/

Geometry was simplified, textures were compressed, and materials are replaced
at runtime for this website’s technical wireframe presentation.
